# bethrudden.ai

The source for [bethrudden.ai](https://bethrudden.ai), Beth Rudden's professional site.

This is a deliberately small, dependency-free static site hosted with GitHub Pages. It presents Beth's work in enterprise AI, AI governance, and control infrastructure for regulated environments.

## Structure

- `index.html` — homepage and selected work
- `work.html` — advisory, board, and selected speaking engagements
- `cv.html` — web CV
- `privacy.html` — privacy, cookie, analytics, and accessibility statement
- `analytics-consent.js` — consent-aware GA4 event tracking
- `Beth-Rudden-CV.pdf` — downloadable CV
- `robots.txt` and `sitemap.xml` — search-engine metadata
- `CNAME` — custom-domain configuration

## Development

No build step is required. Open `index.html` in a browser or serve the directory with any static file server.

## Career content and downloadable CV

`content/career.json` records the leadership introduction, five career outcomes, and appointment language supplied by Beth on October 15, 2026. Keep the homepage and web CV aligned with this wording. IBM Distinguished Engineer is an appointment; do not qualify it as former. The five outcomes support the story of leading people and businesses rather than replacing it with a catalogue of metrics.

After editing `cv.html`, regenerate the downloadable PDF with `python scripts/build_cv.py` using Python with `reportlab` and `lxml` installed. The builder reads the web CV so the public text and download stay consistent. Render and visually inspect the PDF before publishing.

`content/recent-work.json` records dated appearances, publications, and upcoming sessions verified on October 15, 2026. The full web CV includes these entries; the homepage features selected recent work. Keep upcoming sessions explicitly labeled and preserve direct source links in the downloadable PDF. The separate one-page executive CV is not generated by this repository.
